# 📊 Survey App

A React-based web application that allows users to complete surveys by providing personal information, rating items, and selecting food preferences. The app processes and displays survey statistics in-memory for quick analysis and feedback.

---

## 🚀 Features

- Collects user details: name, email, age, gender, etc.
- Includes multiple-choice and rating questions.
- Food preference selections (checkboxes or multiple select).
- Calculates and displays:
  - Average ratings
  - Most preferred items
  - Total submissions
- Real-time, in-memory data handling (no backend/database required).
- Clean, responsive, and user-friendly interface.

---

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS (or your styling choice)
- **State Management:** React Hooks (useState, useEffect)
- **Charts/Visuals:** (optional) Recharts / Chart.js / any preferred chart library

## 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/survey-app.git
   cd survey-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm start
   ```
